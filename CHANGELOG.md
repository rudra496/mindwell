# Changelog — MindWell

All notable changes are documented here. Format follows [Keep a Changelog](https://keepachangelog.com).

## [1.1.0] — 2026-06-05

### Added
- .editorconfig and .gitattributes for consistent formatting
- SUPPORT.md, CHANGELOG.md, ROADMAP.md documentation
- Dependabot config (npm + GitHub Actions)
- Stale issue/PR auto-management workflow
- Auto-labeling for PRs (src, components, content, docs, ci, config)
- New contributor welcome workflow
- Connect section with social links in README

### Added
- Initial release: MindWell Android APK
- 22 mental health disorder info and support modules
- Next.js web platform with Prisma database
- Capacitor mobile app wrapper
- Comprehensive content system (messages, content, scripts)
- Medical disclaimer, privacy policy, safety guidelines
- Deployment guides (Vercel, Play Store)
