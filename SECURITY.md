# Security Policy

## Supported Versions

The following table shows which versions of **MindWell** currently receive security updates.

| Version | Supported |
|--------|-----------|
| main / latest | ✅ Yes |
| Previous releases | ❌ No |

> Only the **latest version on the `main` branch** is actively maintained with security patches.  
> Users are strongly advised to upgrade to the latest version.

---

## Reporting a Vulnerability

We take the security of **MindWell** seriously. If you discover a security vulnerability, please report it responsibly.

### 🔒 How to Report
- **Email:** rudrasarker130@gmail.com  
- **Subject:** `Security Vulnerability Report – MindWell`
- **Include:**
  - A clear description of the vulnerability
  - Steps to reproduce (proof of concept if possible)
  - Affected files, endpoints, or components
  - Potential impact assessment

### ⏱ Response Timeline
- **Acknowledgement:** within **48 hours**
- **Initial assessment:** within **5 business days**
- **Fix & disclosure:** as soon as reasonably possible after validation

### 🚫 Please Do Not
- Publicly disclose the vulnerability before a fix is released
- Open public GitHub issues for security-related reports
- Exploit the vulnerability beyond proof-of-concept testing

### ✅ Responsible Disclosure
If the vulnerability is confirmed, we will:
- Credit the reporter (if desired)
- Patch the issue promptly
- Release an update with clear security notes

Thank you for helping keep **MindWell** and its users safe.
