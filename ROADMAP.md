# Roadmap — MindWell

This document outlines planned features and improvements. Contributions welcome — see [CONTRIBUTING.md](CONTRIBUTING.md).

> Last updated: June 2026

## Planned Features

### Q3 2026
- [ ] AI-powered mood tracking and journaling
- [ ] Peer support community features
- [ ] Crisis resource integration with local hotlines
- [ ] Offline-first PWA support

### Q4 2026
- [ ] iOS app release (via Capacitor)
- [ ] Therapist directory and matching
- [ ] Guided meditation and breathing exercises library
- [ ] Progress tracking and analytics dashboard

## Completed

- [x] 22 mental health disorder modules with comprehensive info
- [x] Next.js web platform
- [x] Android APK release
- [x] Prisma database integration
- [x] Medical disclaimer and safety guidelines
- [x] Deployment guides (Vercel, Play Store)
